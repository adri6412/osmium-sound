# Osmium Sound Companion — docs

This folder holds the few documents that ship with the Android companion app
and its upstream lineage:

- [`LICENSE.md`](LICENSE.md) — Apache License 2.0 (applies to this app, as to
  upstream android-squeezer).
- [`NEWS.md`](NEWS.md) — changelog generated from
  `HiFiMediaPlayer/src/main/res/xml/changelog_master.xml` (`bash gradlew
  generateNews`); entries up to 2.4.x are upstream Squeezer's history.
- [`PRIVACY.md`](PRIVACY.md) — what the app does (and doesn't) with your data.
- [`Beta-testing.md`](Beta-testing.md) — how to get early builds.

The app itself is documented in [`../README.md`](../README.md) and
[`../../COMPANION_APP.md`](../../COMPANION_APP.md); building in
[`../BUILD_INSTRUCTIONS.md`](../BUILD_INSTRUCTIONS.md); releasing in
[`../RELEASE_PROCESS.md`](../RELEASE_PROCESS.md).
