Get started

Download & install

Flash one ISO image to a USB stick for the first install. From then on, every update — UI, system and OS — is delivered automatically over the air.

⚠️ Standard x86 PCs with UEFI firmware only. UEFI is mandatory — legacy BIOS-only machines are not supported. Chromebooks and Intel-based Macs are not supported either: their firmware is locked down by the manufacturer and refuses to boot anything else, unless you flash third-party modified firmware (not provided or endorsed by the manufacturer) and/or use drivers dedicated to that specific platform — neither of which this project provides or supports.

⚠️ Were you in the private beta on a Debian 12 build? You need to reinstall from the latest ISO below: starting with the next release, Debian 12 is no longer supported and will not receive over-the-air updates any more — so you will not be able to update from it.

The simplest way

Osmium Flasher downloads the image itself, checks its signature and writes the stick for you, then walks you through booting the mini PC and running the installer on it. No other tool, and no chance of picking the wrong disk — your system drive is never even listed. Pick the computer you will prepare the stick on, not the mini PC.

Download Osmium Flasher

There is no macOS build. macOS guards raw disk devices with a permission it grants by code signature, and an unsigned application cannot obtain it — the app could fetch and verify the image, but never write it.

Download the image below and write it with balenaEtcher instead. It is signed and notarized by its makers, so macOS lets it do what it needs to. Everything after that — booting the mini PC and running the installer — is exactly the same.

Heads up: the app is not code-signed, so Windows and macOS will warn you the first time you open it. That is expected, and the note below says how to get past it.

Windows — “unknown publisher”

Osmium Flasher is not code-signed, so SmartScreen stops it the first time. Click More info, then Run anyway. Windows will also ask for administrator rights: writing to a raw device needs them.

Linux — one executable file

Make it executable with chmod +x Osmium-Flasher-*.run and run it. No warning to dismiss; you will get a polkit password prompt when the write starts. It is a self-extracting executable rather than an AppImage on purpose — an AppImage is mounted so that root cannot read it, which is exactly what the elevated write needs to do.

Rather write the stick yourself? Download the image and use balenaEtcher, Rufus or dd.

Boot & install

Turn Secure Boot off in the firmware setup first — it is required on every machine. Then boot your x86 mini-PC from the stick and follow the on-screen installer. Reboot — you're done.

Note: the installer asks which disk to install on before formatting it — nothing is wiped without confirmation (tested on UEFI; the ISO is only needed for the first install, every later version arrives automatically over the air).

Try it live: pick Try Osmium Sound (no install) at the boot menu to run the kiosk straight from the USB stick, nothing written to disk. If it doesn't log in automatically, use hifi / hifi at the login screen.

This is Osmium Sound's first public release — it isn't exempt from problems. On the platforms we tested, every feature has been verified and validated, but the x86 hardware landscape is vast, and we can't rule out issues on other hardware combinations. If you run into one, please report it through the official channels below — it really helps.

Mobile companion

Android companion app

Control Osmium Sound from your phone. Browse your library, drive playback and the queue, and adjust volume — pair in seconds by scanning the QR code on the device's Settings screen.

Download APKv1.0.6 Release notes Add F-Droid repo
1

Download the APK

Grab HiFiMediaPlayer-companion-v1.0.6-release.apk using the button above.

2

Install it

Open the APK on your phone and allow install from unknown sources when prompted. Requires Android 8.0 or newer.

3

Pair by QR

On the same Wi-Fi, open the app and scan the pairing QR code from the device's Settings → Phone control.

On iPhone and iPad

There is no Osmium companion app for Apple devices. We suggest LyrPlay, a third-party app by Eric Miller: it connects to the Lyrion Music Server running on your Osmium device, gives you the Material interface to drive playback, and can also turn the iPhone or iPad itself into another player on the network. It is free, with an optional paid icon pack. It is not our app, we have no connection with its author and we cannot support it — we are simply recommending something that works well with Osmium Sound.

LyrPlay on the App Store

Scan it to open LyrPlay in the App Store on your phone.

Note: the companion app is distributed as a signed APK (sideload) or via our self-hosted F-Droid repo — it is not on the Play Store. Prefer F-Droid if you want automatic updates: tap Add F-Droid repo above (F-Droid app required), or add https://osmiumsound.it/fdroid/repo manually under Settings → Repositories. Your phone and the appliance must be on the same local network.
