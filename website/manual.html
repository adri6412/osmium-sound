Osmium Sound

Complete installation and configuration manual. A bit-perfect hi-fi network streamer built on Debian, with Lyrion Music Server and web administration

QR-code setup No mouse/keyboard required Signed OTA updates With screen · Headless · Server-only

UEFI firmware is mandatory

Osmium Sound installs and boots only on PCs with UEFI firmware, started in UEFI mode. Machines with a legacy BIOS only, or set to "Legacy"/"CSM" boot, are not supported. As a rule of thumb, any PC built from 2015 onwards is fine — in particular platforms based on these CPU families all ship UEFI firmware:

  • Intel: Core i3/i5/i7/i9 from the 6th generation "Skylake" (2015) onwards — so 7th to 14th generation and Core Ultra too; the low-power Celeron/Pentium/Atom/N-series families "Braswell" (2015), "Apollo Lake" (2016), "Gemini Lake" (2017–2019), "Jasper Lake" (2021), "Alder Lake-N" (N95/N100/N200/i3-N305, 2023) and "Twin Lake" (N150, 2025) — the chips found in most mini-PCs.
  • AMD: any Ryzen (2017 onwards, every generation) or Athlon on the AM4 socket; the A-series APUs "Carrizo" (2015) and "Bristol Ridge" (2016).

Avoid Atom "Bay Trail"/"Cherry Trail" tablets and HDMI sticks (2013–2015): many of them have a 32-bit UEFI that cannot boot the 64-bit image. Older PCs may work if their firmware offers a UEFI mode, but we don't test them.

Not sure? If the PC came with Windows 8 or newer pre-installed, it has UEFI. On Windows, run msinfo32 and check that "BIOS Mode" says UEFI. In the firmware setup make sure the boot mode is "UEFI" (not "Legacy" or "CSM only"), and when you pick the stick from the boot menu choose the entry that starts with UEFI: rather than the one without the prefix. UEFI yes, Secure Boot no: it has to be turned off, see Installation.

Note

No high-end hardware needed: Osmium Sound runs well on inexpensive or recycled mini-PCs.

Installation

Installation happens entirely from a USB stick, with a full installer built into the device itself. Drive it directly on the mini-PC's screen (mouse/keyboard/touchscreen), or from your phone via the QR code shown in the corner — both work at once, and neither needs the other to get started.

Disable Secure Boot first

Osmium Sound's installer/live USB currently does not boot with UEFI Secure Boot enabled — the mini-PC will refuse to start from the stick, or fail partway through boot. Before plugging in the USB stick, go into your mini-PC's BIOS/UEFI setup (usually F2/Del/Esc at power-on) and disable Secure Boot. You can leave it disabled permanently.

  1. Download the ISO Download the latest version from the download section of the website (it is also on GitHub).
  2. Write the ISO to a USB stick The simplest way is Osmium Flasher, from the download section: it downloads the image, verifies its signature and writes the stick, and it never lists your system disk. Failing that, balenaEtcher, Rufus or the dd command work just as well. Use a stick of at least 8 GB.
  3. Turn Secure Boot off Enter the firmware setup (usually Del or F2), disable Secure Boot, then save and exit. This is needed on every machine: the install image is not signed for Secure Boot and will not start with it enabled.
  4. Boot the mini-PC from the stick Plug in the stick, power on the mini-PC, and pick USB boot from the boot menu (usually F11/F12/Esc depending on the motherboard). Choose Install Osmium Sound from the menu.
  5. Choose the disk, right on the screen The welcome screen offers Choose disk as the main action: tap it and pick the target disk from the list shown on the mini-PC's own screen.
  6. Confirm A clear warning is shown: all data on the chosen disk will be erased. Tap Erase and install to proceed.
  7. Wait for it to finish Progress is shown live on screen. No internet connection is needed for this part. When it's done, the device reboots on its own.
  8. Unplug the USB stick Once the mini-PC has restarted, remove the stick.
Prefer your phone?

A QR code sits in the top-right corner of the screen from the very first frame — no click needed to reveal it, so the whole install can be driven from your phone even with no mouse, keyboard, or touchscreen attached to the mini-PC at all. Scan it, then pick the disk and confirm from there. Whichever side actually starts the install, the mini-PC's screen always mirrors progress.

Without a network cable, the mini-PC opens its own Wi-Fi network called Osmium-Setup-XXXX, with no password: connect your phone to it and the install page opens by itself. If it doesn't, open http://10.42.0.1 in the phone's browser.

Warning

Choosing a disk permanently erases all data on it. Double-check you picked the right disk before confirming, especially if the mini-PC has more than one disk attached.

Try it without installing

From the USB stick's boot menu you can pick Try Osmium Sound (no install) to run the interface straight from the stick, without writing anything to disk — handy for a quick look.

Only needed for the first install

The ISO is only needed to install Osmium Sound the first time. Every later update arrives over the internet (OTA) from the Settings screen — no need to ever reflash the stick again.

First boot and setup

After installation, the first thing the screen asks for is the network: pick your Wi-Fi and type its password, or just plug in a network cable. As soon as the device is online, the screen shows its address (for example http://192.168.1.23). Type it exactly as shown, including http://, into the browser of a phone, tablet or computer — a computer works best, because the music server's page opened at the end doesn't look great on a phone. Setup continues from there, and the screen moves on by itself when it's done: there's no button to press on the device.

Guided setup steps (in the browser)

  1. Language Choose English or Italian for this setup run. It's asked once, up front — there's no way to change it again until you restart the wizard from scratch (the same as a phone's own first-run language screen).
  2. Restore from backup, or start fresh If you've used Osmium Sound before and have a backup file, you can upload it here (with its passphrase, if encrypted): network, audio output, Lyrion, music sources, time zone and your account are all restored automatically and the device reboots on its own. Otherwise, choose to start fresh and continue with the steps below.
  3. Update, if one is needed The device checks whether it must update before going on. If so, it downloads and applies the update, reboots, and setup picks back up right where it left off.
  4. Name this device Optional: give it a name (letters, numbers, and dashes only) — it becomes its network address (e.g. "livingroom" → livingroom.local instead of hifiplayer.local) and the name you'll see in the player list. Leave it empty to keep the default. Worth setting if you'll have more than one Osmium Sound at home, since two units with the same default name get mixed up.
  5. Device mode Choose between With screen, Headless, and Server-only — see Device modes for details.
  6. Mouse pointer With a screen only: hide the pointer for a touchscreen, or show it if you'll use a mouse.
  7. Audio output Select the detected USB DAC or HDMI output. You can change this at any time later from Settings.
  8. Music server (Lyrion) Choose whether this device should be the music server (recommended for the first device in your home), or use a Lyrion server already on your network (for an additional device). A server on the network is found for you; you can also type its address or its name, such as nas.local. If this device is the server, it downloads and installs it now, showing the progress.
  9. Web player look Pick how the music server's web page looks: Osmium (recommended, same style as the device) or the standard Material.
  10. Music services A few short pages — streaming services (Spotify, TIDAL, Qobuz, Deezer), internet radio, information about your music, and whether to send anonymous usage statistics. Tick what you want; nothing is installed until you press Install and continue on the last page, and you can go back and forth freely.
  11. Create your account Only when starting fresh: pick the username and password you'll use for web administration from now on — there's no separate account-creation step later, it's part of this same wizard.
  12. Time zone Set the correct time zone for the clock, alarms, and scheduling.
  13. Music sources Optional: add a network drive (NAS) and/or set up an internal disk for your music library — USB drives already mount automatically, so there's nothing to do for those. For a network drive the device looks for the computers and NAS on your network and lists their shared folders: pick one, and if it asks for a username and password a small window appears for them. An internal disk can be used as-is or formatted first (ext4 or exFAT — this erases everything on it and asks you to type the disk's name to confirm). Add as many as you like, then press Done, continue. You can always add more later from Settings.
  14. Finish setup Press "Complete setup". The device switches to the mode you chose and, if it is the music server, your browser opens its web player, ready to use.
Renamed the device? Use its IP address instead

hifiplayer.local is only the default address — it's really <device-name>.local, and it changes the moment you (or a previous setup) pick a different name in the step above. It also isn't unique: two devices that both still have the default name answer to the same hifiplayer.local, and one of them silently wins. The address that always works, regardless of name, is the device's IP address — see Web administration.

No certificate warnings

Osmium Sound's web administration is plain HTTP — there's no TLS certificate to trust or click through. A per-device self-signed certificate was tried and dropped: it just meant an extra "connection not private" warning on first visit, for no real gain on a local-only address like hifiplayer.local.

Device modes

Osmium Sound supports three operating modes, chosen during setup and changeable at any time from Settings:

With screen

The touchscreen kiosk interface is always visible. Ideal for a player sitting next to your hi-fi system, with a screen available.

Headless

No on-screen interface, but the player still plays audio locally. Managed from web administration, the companion app, or Lyrion.

Server-only

No screen and no local audio playback. Lyrion Music Server keeps running to serve other Osmium Sound devices in your home — ideal for a "server" unit tucked away in a closet.

The two underlying settings are independent of each other:

SettingWhereWhat it controls
Display modeSettings → Display modeWith screen (touchscreen kiosk) ⇄ Headless (no screen)
PlayerSettings → PlayerOn ⇄ Off (no local audio playback, still serves other devices)

Server-only = Display mode set to Headless + Player set to Off, applied together.

Bringing "with screen" mode back

If a device is in headless or server-only mode and you want to turn the screen back on, open web administration or the companion app and go to Settings → Display mode.

Web administration

Every Osmium Sound device exposes a web administration page reachable from any browser on the same network — especially useful for headless or server-only devices, but always available. The address to use is the device's IP address, visible in Settings → System info (on screen or in the companion app), the web admin session itself, or your router's device list:

AddressWhat's there
http://<device-ip>Web administration: network, audio output, music sources and files, the Library editor, Lyrion Music Server, playback, VU meters, animations, display mode, player on/off, time zone, updates, companion pairing, account, backup, SSH, Tailscale, restart/shut down, factory reset
http://<device-ip>:9000Lyrion Music Server's own web interface (library, playlists, server settings)

The home page also has a Disk space card: a bar and a small table telling how much the system takes, how much your data uses, and how much is still free.

From Settings → Music sources → Manage files you get a file manager for the music on the device, on its internal disks, on network folders and USB drives, and for the playlists: create folders, rename, copy, cut, paste and delete, as on a computer. It is only in web administration, not on the device's screen.

Library (the link at the top of web administration, or http://<device-ip>/library, with the same account) is for putting right what the album and artist pages show:

  • Tags in the files — fix an album's name, artist, year, genre, composer and the details of each track; the changes are written into the music files and the library updates by itself. Every save can be undone from History. Only folders the device can write to can be changed, and until the next full system update only FLAC files.
  • Online credits — correct a misspelled name, link a person to the right artist, take someone off a credit or hide a whole line, change a role or an instrument, add a missing credit, or choose the right edition of the album. These corrections stay on the device, leave the music files untouched and are included in backups; Back to MusicBrainz undoes them. The album page then says the credits were corrected by hand.
  • Artists — choose which MusicBrainz artist a name really is, show a different name or hide the biography.
What about hifiplayer.local?

The device also answers at http://hifiplayer.local by default — a shortcut, not a fixed address. It's really <device-name>.local, so it stops working (or points at a different device) the moment you rename the device, and it's ambiguous the moment you have more than one Osmium Sound with the same name on the network. The IP address is the one that's always correct.

Android companion app

Control Osmium Sound from your phone: browse the library, control playback and the queue, adjust volume. Not available on Google Play — distributed as a signed APK or via the project's self-hosted F-Droid repository.

  1. Install the app Download the APK from the project's Releases, or add the F-Droid repository — details on the official website.
  2. Pair the device From the device's screen (if in "with screen" mode), go to Settings and show the pairing QR code; or, for a headless/server-only device, generate the QR from web administration. Scan it from the app.
  3. Use the app Once paired, the app talks directly to Lyrion and the device's API on the local network.

The device settings are grouped under Settings → Osmium Sound, with the same sections as web administration: audio output, music sources, services, Lyrion Music Server, playback and VU meters (including the looks to download), display, time zone, updates, iPhone/iPad, backup & restore, and system. A few things stay in web administration only, on purpose: network, the SSH login, the web account, factory reset and the debug tools. The Now Playing animations are chosen on the device's screen or in web administration, not in the app. With an older device, sections it doesn't support yet simply don't appear.

Once paired, a power icon in the app's top bar turns the Osmium Sound device off, after asking for confirmation.

The first time you open the app it asks for your language, then what you are connecting to. Choose Osmium Sound to scan the pairing code and get the device settings listed above, or another Lyrion server to type in an address and port instead — in that case the device settings are not shown, because there is no Osmium device behind them. If the connection doesn't work, the "Trouble connecting?" guide on that screen walks you through the usual causes.

Listening on the phone itself

The phone can also be one of the players in the house. It appears in the player list with its own name, next to the Osmium device and any other player, and you pick it the same way. The music then comes out of the phone's speaker or headphones, while everything else — the library, the queue, the volume — keeps working as usual.

In Settings, under "This phone as a player", you can turn it off, rename it, and choose how good the sound should be, separately for Wi-Fi and mobile data. The best quality sounds better and moves from one track to the next with no gap; the lighter ones use much less data.

On iPhone and iPad

There is no Osmium companion app for Apple devices. We suggest LyrPlay, a third-party app by Eric Miller: it connects to the Lyrion Music Server running on your Osmium device, gives you the Material interface to drive playback, and can also turn the iPhone or iPad itself into another player on the network. It is free, with an optional paid icon pack. It is not our app, we have no connection with its author and we cannot support it — we are simply recommending something that works well with Osmium Sound.

Daily use

  • Now Playing — the expanded view shows the analog VU meters (see VU meters) — or, with them off, an animation (see Animations) — and a status plate: the kind of audio playing (Hi-Res, PCM, DSD) and whether BitPerfect or ReplayGain is on. Tap BitPerfect or ReplayGain to jump straight to the setting behind it.
  • Choosing the player — tap the player name in the bar at the bottom (or the speaker button in Now Playing) to see the other players on the same music server, and pick one to control it from this screen: what's playing, the queue, the volume. The name turns gold as a reminder. Settings that belong to this device are hidden meanwhile, with a Back to this device button; after a restart the screen is always back on its own player.
  • Power button — the power icon at the right end of the top bar, next to the Osmium Sound mark, restarts or shuts down the device.
  • Music / Radio / Apps — Lyrion Music Server's interface: local library, internet radio, and streaming services (Deezer, Qobuz, TIDAL, Spotify and others) via Lyrion plugins. The Music tab opens on a search box that looks through the whole library (artists, albums, tracks) and on tiles for artists, albums, genres, years, composers, new music, folders, playlists and favourites.
  • Album and artist pages — tap an album to open its page: cover, year, length and format, buttons to play, shuffle or queue it, the tracks (tap one to start the album from there) and the credits written in your music files. Tap an artist — in the library, on an album page, or under the title in Now Playing — for their page, with their albums grouped by what they did on them: as the artist, with a band or orchestra, as composer, as conductor, appearing on someone else's record. With an internet connection the pages also show who played what and on which instrument, who produced and recorded the album and where, when it first came out, the members of a band and a short biography, taken from MusicBrainz and Wikipedia. If an album page shows a different record from yours, tap Wrong album? Choose the edition at the bottom.
  • Favourites and playlists — the heart in Now Playing adds or removes what is playing from the favourites; press and hold any row (a track, an album, a radio station, a playlist) for more: add to the queue, play next, add to favourites. In Favourites you can rename, reorder and remove; playlists can be renamed, deleted and trimmed of a track.
  • Refreshing the library — Settings → Lyrion Music Server shows how many albums, artists and tracks the server knows, when it last scanned, and a Refresh the library button with progress (also on the web administration Dashboard). Sources you add or change are scanned on their own; use this after moving music around by hand. In the same section, Album and artist information turns the online look-ups for the album and artist pages on or off, can prepare the whole library slowly in the background so the pages open complete, and clears what has been saved. To find the information, the device sends the names of your albums and artists to MusicBrainz and Wikipedia.
  • CD — insert a disc to play it, or rip it to FLAC with automatic tags and cover art (MusicBrainz), straight into your library, an adopted USB drive, or a writable network share. A ripped album is recognised right away on its album page.
  • Discover — endless mixes by track, album, or artist, with a genre filter and saveable presets, plus "keep playing similar music", related artists, and bios, right on the touchscreen.
  • Settings → Playback — track transition, ReplayGain, the now-playing auto-expand timeout, and a fixed-volume-100% (BitPerfect) toggle that turns off Lyrion's own digital volume control and greys out the volume slider.
  • Settings — system and network info, audio output, music sources, Lyrion Music Server, VU meters, animations, updates, companion app pairing, backup, factory reset.
Playback survives a restart

Osmium Sound remembers what was playing — track, position, and whether it was playing or paused — across a reboot or shutdown, and picks back up on its own once the device is back online.

VU meters

Now Playing can show a pair of analog VU meters whose needles move with the music. Everything about them is in Settings → VU meters — on the screen, in web administration, or in the companion app:

  • On or off — turn them off if you prefer a cleaner screen.
  • Look — pick one of the styles from its preview: six come with the device (Classic, Modulometer, Amber, Ice Blue, Exposed, Panoramic).
  • More to download — in the same section you'll find further looks to download. A new one is only offered, never installed on its own; a gold dot tells you something new is there. Once downloaded, a look keeps itself up to date, stays after system updates, and can be removed at any time (if it was in use, the device goes back to Classic).
Only looks we have checked

The downloadable looks come from Osmium Sound's own list, and the device refuses anything that doesn't match it exactly. A look that needs a newer version of the device says so, instead of installing.

Animations

With the VU meters turned off, Now Playing can show an animation in their place. Choose it in Settings → Animations — on the screen or in web administration:

  • None — nothing takes the place of the VU meters.
  • CD — a disc goes into a player, then spins.
  • Vinyl — the tonearm lowers onto a record, then the record spins.
  • Cassette — a tape goes into a deck, then runs.

It moves only while music is playing: pause, and it slows down and stops. When a new album starts, the disc or tape comes out and goes back in. The button in Now Playing that brings up the song lyrics switches between the animation and the lyrics.

VU meters or animation

The animations play on the device's screen only, and only while the VU meters are off. To see one, turn off Settings → VU meters first.

Music sources

Osmium Sound reads your music library from one or more sources, configurable from Settings (or during initial setup):

  • Network folder — a NAS or a shared folder on another computer. You don't need to know its address: the device looks for the computers and NAS on your network, lists their shared folders, and asks for a username and password in a small window only if the folder needs them. If it can't connect, it tells you why in plain words (the technical details stay one tap away). You can still type everything in by hand. Each folder can be toggled between read-only and writable at any time — handy if you also want to rip CDs onto it.
  • USB disk — a USB disk plugged into the device, "adopted" (shared on the network, read/write). An adopted drive auto-remounts on its own if you unplug and reconnect it, or reconnect it after a reboot.
  • Internal disk — a second disk inside the device, dedicated to music.
  • A folder on the device itself — music copied straight onto the device's own disk. It can be shared on the network so you can copy music into it from a computer.

After adding or editing a source, the library is updated on its own. In web administration, Music sources is a menu — active sources, add a source, playlist folder, shared folders, manage files — where each screen has a way back.

Under Playlist folder you choose where playlists are saved; share it on the network to copy playlists onto the device. Playlists made on Windows are fixed automatically so they play here too.

External Lyrion server

If the device follows a Lyrion Music Server already running elsewhere on your network (chosen during setup, or in Settings → Lyrion Music Server), the Music Sources section doesn't appear at all: sources are configured on that other device, not this one.

Streaming & Lyrion plugins

Streaming services (Deezer, Qobuz, TIDAL, Spotify and others) and extra features (UPnP/DLNA, AirPlay, radio) are Lyrion Music Server plugins, not part of the Osmium Sound app itself. The most common ones can already be ticked during setup (the "Music services" step); for the others, or to add one later:

  1. Open Lyrion's web UI http://<device-ip>:9000 — see Web administration for how to find the IP address.
  2. Go to Settings → Plugins Find and enable the plugin for the service you want.
  3. Log in with your credentials Follow the plugin's instructions to log into the service.
  4. Go back to the Osmium Sound interface The new service shows up on its own in the Radio/Apps tabs — no app update needed.

External Lyrion server

Each Osmium Sound device plays through its own Lyrion Music Server by default. From Settings → Lyrion Music Server you can switch between Internal and External (on my network): the second one uses a Lyrion server already running on another device, found for you by a search of your network — you can also type its IP address or its name, such as nas.local. A name that can't be found is refused before anything changes. Switching restarts the device. The same section holds the player name, the Lyrion version and the web player look.

Playing several players in sync (multiroom) is a native Lyrion Music Server feature, managed from Lyrion's own interface — Osmium Sound doesn't provide a separate multiroom feature of its own. Give each device a name so they're easy to tell apart there. From the device's screen you can also control any other player on the same server — see Daily use.

Backup & restore

From Settings you can create a full backup of the device's configuration: audio output, the music source list, Lyrion preferences and playlists, Wi-Fi network profiles, account and pairing tokens. Sensitive data (Wi-Fi networks, account) only enters the backup if you choose to protect it with a passphrase.

  • Manual backup — Settings → Backup → Create backup now, with or without a passphrase.
  • Scheduled backup — enable it in Settings; runs a weekly backup automatically (non-sensitive data only, since there's nobody to ask for a passphrase).
  • Restore — from Settings on an already-configured device, or directly during first-boot setup (see First boot and setup) to quickly bring a replaced or reset device back up.
Before a restore

The device automatically creates a safety backup of the current state right before applying a restore, so a bad restore is still reversible.

OTA updates

Osmium Sound and Lyrion Music Server update over the internet (OTA, over-the-air) from Settings → Updates — on the screen, in web administration or in the companion app — with no need to ever reflash the USB stick after the initial install. Press Check for updates: within a minute it tells you that an update is available, that you're up to date, or that it couldn't check (usually a network problem).

The whole system arrives as a single, digitally signed package: the device refuses anything that isn't signed correctly, even if someone managed to tamper with the download. The device keeps two copies of the system side by side. An update is written into the copy that isn't in use, while the device carries on working, with the progress shown live; the restart at the end switches over to it. If the new version doesn't start properly, the device goes back to the previous one on its own, within about ten minutes. Your settings, your music and everything you downloaded are kept apart from the system, so an update never touches them.

Devices installed before the two-copy system

An older device moves to the new arrangement with a normal update — no reinstall, and settings and music are kept. That one update takes longer than usual and restarts the device a few times on its own; let it finish without switching it off.

Each device can pick a release channel in Settings → Updates:

ChannelDescription
Prod (default)Stable releases, recommended for everyday use
DevMore frequent development builds, for trying new things early
Reboot at the end

Once every step of an update has been applied, the device reboots on its own to complete it — this is expected, and playback resumes automatically afterwards (see Daily use).

SSH & advanced access

SSH access is off by default. It can be turned on from Settings (on-screen or from web administration → Services) for advanced maintenance or debugging. Right under the switch you choose the username and password to log in with; the panel then shows the exact ssh command to use.

Security

When SSH is enabled, logging in as root stays blocked regardless: it's not possible to log in directly as the system administrator over SSH.

Installing extra programs

The system itself can't be modified, but over SSH the usual sudo apt install <package> still works: the extra program is kept apart from the system, and sudo apt remove takes it away again. After a system update the device rebuilds your extra programs for the new version by itself when it starts (it needs the internet for that). A package that would replace part of the system, or needs newer system components than the device has, is refused with an explanation. The system itself is not updated with apt upgrade but from Settings → Updates.

Remote access (Tailscale)

Web administration also offers optional remote access via Tailscale, so you can reach the device from outside your home network — into your own Tailscale account, not a vendor-run service.

  1. Install Tailscale From web administration → Settings → Tailscale, install it on the device if it isn't already present.
  2. Enable it Turning it on opens a one-time login URL — open it in a browser and sign in to your own Tailscale account (or create one) to authorize the device onto your tailnet.
  3. Connect from anywhere Once connected, the device's Tailscale IP and connection details (including DERP relay region/latency) are shown in the same Settings section. Reach web administration through that address from any other device on your tailnet.
Web administration only

Tailscale is currently only available from web administration — it doesn't appear in the on-screen Settings or in the Android companion app.

Factory reset

Factory reset erases every setting, the web administration account, configured sources, backups kept on the device and downloaded VU meter looks, then reboots the device straight back into the setup described in First boot and setup — as if it had just been installed. Music copied onto the device itself is kept.

Available from:

  • On-screen, in Settings → System Controls → Factory reset (if the device is in "with screen" mode).
  • Web administration, by entering the administrator account's password.
Forgot the password?

If you forget the web administration password, you can reset it from on-screen Settings (if available), or proceed with a factory reset.

Firmware UEFI obbligatorio

Osmium Sound si installa e si avvia solo su PC con firmware UEFI, avviati in modalità UEFI. Le macchine con solo BIOS legacy, o impostate sull'avvio "Legacy"/"CSM", non sono supportate. Come regola pratica va bene qualsiasi PC prodotto dal 2015 in poi — in particolare le piattaforme basate su queste famiglie di CPU hanno tutte firmware UEFI:

  • Intel: Core i3/i5/i7/i9 dalla 6ª generazione "Skylake" (2015) in poi — quindi anche dalla 7ª alla 14ª generazione e Core Ultra; le famiglie a basso consumo Celeron/Pentium/Atom/serie N "Braswell" (2015), "Apollo Lake" (2016), "Gemini Lake" (2017–2019), "Jasper Lake" (2021), "Alder Lake-N" (N95/N100/N200/i3-N305, 2023) e "Twin Lake" (N150, 2025) — i chip della maggior parte dei mini-PC.
  • AMD: qualsiasi Ryzen (dal 2017, tutte le generazioni) o Athlon su socket AM4; le APU serie A "Carrizo" (2015) e "Bristol Ridge" (2016).

Evita invece tablet e "stick" HDMI con Atom "Bay Trail"/"Cherry Trail" (2013–2015): molti hanno un UEFI a 32 bit che non può avviare l'immagine a 64 bit. PC più vecchi possono funzionare se il firmware offre la modalità UEFI, ma non li testiamo.

Non sei sicuro? Se il PC è stato venduto con Windows 8 o successivo preinstallato, ha l'UEFI. Su Windows esegui msinfo32 e controlla che "Modalità BIOS" indichi UEFI. Nel setup del firmware verifica che la modalità di avvio sia "UEFI" (non "Legacy" o "CSM only") e, quando scegli la chiavetta dal menu di boot, usa la voce che inizia con UEFI: anziché quella senza prefisso. UEFI sì, Secure Boot no: va disattivato, vedi Installazione.

Nota

Non serve un dispositivo di fascia alta: Osmium Sound gira bene su mini-PC economici o riciclati.

Installazione

L'installazione avviene interamente da chiavetta USB, con un installer completo integrato nel dispositivo stesso. Guidala direttamente sullo schermo del mini-PC (mouse/tastiera/touchscreen), oppure dal telefono tramite il QR code mostrato nell'angolo — funzionano entrambi contemporaneamente, e nessuno dei due richiede l'altro per iniziare.

Disattiva prima il Secure Boot

L'installer/chiavetta live di Osmium Sound al momento non si avvia con il Secure Boot UEFI attivo — il mini-PC si rifiuterà di avviarsi dalla chiavetta, oppure il boot si interromperà a metà. Prima di collegare la chiavetta USB, entra nel setup BIOS/UEFI del mini-PC (di solito F2/Canc/Esc all'accensione) e disattiva il Secure Boot. Puoi lasciarlo disattivato in modo permanente.

  1. Scarica la ISO Scarica l'ultima versione dalla sezione download del sito (è anche su GitHub).
  2. Scrivi la ISO su una chiavetta USB Il modo più semplice è Osmium Flasher, dalla sezione download: scarica l'immagine, ne verifica la firma e scrive la chiavetta, senza mai elencare il disco di sistema. In alternativa vanno bene balenaEtcher, Rufus o il comando dd. Serve una chiavetta da almeno 8 GB.
  3. Disattiva il Secure Boot Entra nel setup del firmware (di solito Canc o F2), disattiva il Secure Boot, poi salva ed esci. Serve su tutte le macchine: l'immagine di installazione non è firmata per il Secure Boot e con quello attivo non parte.
  4. Avvia il mini-PC dalla chiavetta Collega la chiavetta, accendi il mini-PC e seleziona l'avvio da USB dal menu di boot (di solito F11/F12/Esc a seconda della scheda madre). Scegli Install Osmium Sound dal menu.
  5. Scegli il disco, direttamente sullo schermo La schermata di benvenuto propone Choose disk come azione principale: toccala e scegli il disco di destinazione dall'elenco mostrato sullo schermo del mini-PC.
  6. Conferma Viene mostrato un avviso chiaro: tutti i dati sul disco scelto verranno cancellati. Tocca Erase and install per procedere.
  7. Attendi il completamento L'avanzamento è mostrato in tempo reale a schermo. Per questa parte non serve la connessione a internet. Al termine, il dispositivo si riavvia automaticamente.
  8. Scollega la chiavetta USB Quando il mini-PC si è riavviato, rimuovi la chiavetta.
Preferisci il telefono?

Un QR code compare nell'angolo in alto a destra dello schermo fin dal primo istante — non serve nessun tocco per farlo apparire, quindi l'intera installazione può essere guidata dal telefono anche senza mouse, tastiera o touchscreen collegati al mini-PC. Scansionalo, poi scegli il disco e conferma da lì. Indipendentemente da chi avvia effettivamente l'installazione, lo schermo del mini-PC mostra sempre l'avanzamento in tempo reale.

Senza cavo di rete, il mini-PC accende una sua rete Wi-Fi chiamata Osmium-Setup-XXXX, senza password: collega il telefono a quella rete e la pagina di installazione si apre da sola. Se non succede, apri http://10.42.0.1 nel browser del telefono.

Attenzione

La scelta del disco cancella tutti i dati presenti su quel disco, in modo permanente. Verifica di aver selezionato il disco giusto prima di confermare, specialmente se il mini-PC ha più di un disco collegato.

Provarlo senza installare

Dal menu di avvio della chiavetta puoi scegliere Try Osmium Sound (no install) per far partire l'interfaccia direttamente dalla USB, senza scrivere nulla sul disco — utile per una prova rapida.

Solo per la prima installazione

La ISO serve solo per installare Osmium Sound la prima volta. Tutti gli aggiornamenti successivi arrivano via internet (OTA) dalla schermata Impostazioni — non serve mai riflashare la chiavetta.

Primo avvio e configurazione

Dopo l'installazione, la prima cosa che lo schermo chiede è la rete: scegli il tuo Wi-Fi e scrivi la password, oppure collega semplicemente un cavo di rete. Appena il dispositivo è in rete, lo schermo mostra il suo indirizzo (per esempio http://192.168.1.23). Scrivilo esattamente come appare, http:// compreso, nel browser di un telefono, un tablet o un computer — meglio un computer, perché la pagina del server musicale che si apre alla fine non si vede benissimo su un telefono. La configurazione prosegue da lì, e lo schermo va avanti da solo quando hai finito: sull'apparecchio non c'è nessun pulsante da premere.

Passaggi della configurazione guidata (nel browser)

  1. Lingua Scegli Inglese o Italiano per questa configurazione. Viene chiesto una sola volta, all'inizio — non c'è modo di cambiarla di nuovo finché non riavvii la procedura guidata da zero (come la schermata di scelta della lingua al primo avvio di un telefono).
  2. Ripristina da backup, oppure inizia da zero Se hai già usato Osmium Sound in passato e hai un file di backup, puoi caricarlo qui (con la relativa passphrase, se cifrato): rete, uscita audio, Lyrion, sorgenti musicali, fuso orario e account vengono ripristinati automaticamente e il dispositivo si riavvia da solo. Altrimenti, scegli di iniziare da zero e prosegui con i passaggi seguenti.
  3. Aggiornamento, se serve Il dispositivo controlla se deve aggiornarsi prima di proseguire. In quel caso scarica e applica l'aggiornamento, si riavvia, e la configurazione riprende esattamente da dove si era fermata.
  4. Dai un nome a questo dispositivo Facoltativo: assegnagli un nome (solo lettere, numeri e trattini) — diventa il suo indirizzo di rete (es. "salotto" → salotto.local invece di hifiplayer.local) e il nome con cui compare nell'elenco dei player. Lascia vuoto per mantenere quello predefinito. Vale la pena impostarlo se avrai più di un Osmium Sound in casa, perché due unità con lo stesso nome predefinito si confondono.
  5. Modalità del dispositivo Scegli tra Con schermo, Headless e Solo server — vedi la sezione Modalità del dispositivo per i dettagli.
  6. Puntatore del mouse Solo con schermo: nascondi il puntatore per un touchscreen, oppure mostralo se userai un mouse.
  7. Uscita audio Seleziona il DAC USB o l'uscita HDMI rilevata. Si può cambiare in ogni momento più avanti dalle Impostazioni.
  8. Server musicale (Lyrion) Scegli se il server musicale deve essere questo dispositivo (impostazione consigliata per il primo dispositivo in casa), oppure usare un server Lyrion già presente sulla rete (per un dispositivo aggiuntivo). Un server in rete viene trovato da solo; puoi anche scriverne l'indirizzo o il nome, per esempio nas.local. Se il server è questo dispositivo, lo scarica e lo installa adesso, mostrando l'avanzamento.
  9. Aspetto del player web Scegli l'aspetto della pagina web del server musicale: Osmium (consigliato, con lo stesso stile dell'apparecchio) oppure il classico Material.
  10. Servizi musicali Qualche pagina breve — servizi di streaming (Spotify, TIDAL, Qobuz, Deezer), radio via internet, informazioni sulla musica, e se inviare statistiche d'uso anonime. Spunta quello che ti interessa; non viene installato nulla finché non premi Installa e continua nell'ultima pagina, e puoi andare avanti e indietro liberamente.
  11. Crea il tuo account Solo se inizi da zero: scegli il nome utente e la password che userai da ora in poi per l'amministrazione web — non c'è un passaggio separato più avanti, fa parte di questa stessa procedura guidata.
  12. Fuso orario Imposta il fuso orario corretto per orologio, allarmi e programmazioni.
  13. Sorgenti musicali Facoltativo: aggiungi un disco di rete (NAS) e/o configura un disco interno per la tua libreria musicale — le unità USB si montano già automaticamente, quindi per quelle non serve fare nulla. Per un disco di rete il dispositivo cerca i computer e i NAS della tua rete e ne elenca le cartelle condivise: scegline una, e se chiede nome utente e password compare una piccola finestra dove scriverli. Un disco interno può essere usato così com'è oppure formattato prima (ext4 o exFAT — questo cancella tutto ciò che contiene e chiede di digitare il nome del disco per confermare). Aggiungine quante vuoi, poi premi Fatto, continua. Puoi sempre aggiungerne altre in seguito dalle Impostazioni.
  14. Completa il setup Premi "Completa setup". Il dispositivo passa alla modalità scelta e, se il server musicale è lui, il browser apre il suo player web, pronto all'uso.
Hai rinominato il dispositivo? Usa il suo indirizzo IP

hifiplayer.local è solo l'indirizzo predefinito — è in realtà <nome-dispositivo>.local, e cambia nel momento in cui tu (o una configurazione precedente) scegli un nome diverso al passaggio sopra. Non è nemmeno univoco: due dispositivi che hanno entrambi ancora il nome predefinito rispondono allo stesso hifiplayer.local, e uno dei due vince silenziosamente. L'indirizzo che funziona sempre, a prescindere dal nome, è l'indirizzo IP del dispositivo — vedi Amministrazione web.

Nessun avviso di certificato

L'amministrazione web di Osmium Sound è in HTTP semplice — non c'è nessun certificato TLS da approvare. Un certificato autofirmato per dispositivo era stato provato e poi scartato: significava solo un avviso "connessione non privata" in più al primo accesso, senza reale vantaggio su un indirizzo solo locale come hifiplayer.local.

Modalità del dispositivo

Osmium Sound supporta tre modalità operative, scelte durante il setup e modificabili in ogni momento dalle Impostazioni:

Con schermo

Interfaccia touchscreen kiosk sempre visibile. Ideale per un lettore vicino all'impianto hi-fi, con schermo a disposizione.

Headless

Nessuna interfaccia a schermo, ma il player riproduce comunque audio in locale. Si gestisce da amministrazione web, app companion o Lyrion.

Solo server

Nessuno schermo e nessuna riproduzione audio locale. Lyrion Music Server continua a funzionare per servire altri dispositivi Osmium Sound in casa — ideale per un'unità "server" in un ripostiglio/armadio tecnico.

Le due impostazioni sono indipendenti tra loro:

ImpostazioneDoveCosa controlla
Modalità schermoImpostazioni → Modalità schermoCon schermo (kiosk touchscreen) ⇄ Headless (nessuno schermo)
PlayerImpostazioni → PlayerAcceso ⇄ Spento (nessuna riproduzione audio locale, resta un server per altri dispositivi)

Solo server = Modalità schermo su Headless + Player su Spento, applicati insieme.

Come tornare a "Con schermo"

Se un dispositivo è in modalità headless o solo server e vuoi riaccendere lo schermo, apri l'amministrazione web o l'app companion e vai su Impostazioni → Modalità schermo.

Amministrazione web

Ogni dispositivo Osmium Sound espone una pagina di amministrazione web raggiungibile da qualsiasi browser sulla stessa rete, utile in particolare per i dispositivi in modalità headless o solo server, ma disponibile sempre. L'indirizzo da usare è l'indirizzo IP del dispositivo, visibile in Impostazioni → Info di sistema (a schermo o nell'app companion), nella sessione di amministrazione web stessa, oppure nell'elenco dispositivi del router:

IndirizzoCosa trovi
http://<ip-dispositivo>Amministrazione web: rete, uscita audio, sorgenti musicali e file, la Libreria, Lyrion Music Server, riproduzione, VU meter, animazioni, modalità schermo, player on/off, fuso orario, aggiornamenti, abbinamento app companion, account, backup, SSH, Tailscale, riavvio/spegnimento, reset di fabbrica
http://<ip-dispositivo>:9000Interfaccia web di Lyrion Music Server (libreria, playlist, impostazioni server)

La pagina iniziale ha anche un riquadro Spazio su disco: una barra e una piccola tabella che dicono quanto occupa il sistema, quanto i tuoi dati e quanto spazio resta libero.

Da Impostazioni → Sorgenti musicali → Gestisci i file trovi un gestore di file per la musica sull'apparecchio, sui dischi interni, nelle cartelle di rete e sulle chiavette USB, e per le playlist: crea cartelle, rinomina, copia, taglia, incolla ed elimina, come su un computer. C'è solo nell'amministrazione web, non sullo schermo dell'apparecchio.

Libreria (il collegamento in alto nell'amministrazione web, oppure http://<ip-dispositivo>/library, con lo stesso account) serve a sistemare quello che mostrano le pagine di album e artisti:

  • Tag nei file — correggi nome dell'album, artista, anno, genere, compositore e i dettagli di ogni brano; le modifiche vengono scritte nei file musicali e la libreria si aggiorna da sola. Ogni salvataggio si può annullare dalla Cronologia. Si possono modificare solo le cartelle in cui l'apparecchio può scrivere, e fino al prossimo aggiornamento completo del sistema solo i file FLAC.
  • Crediti dal web — correggi un nome scritto male, collega una persona all'artista giusto, togli qualcuno da un credito o nascondi una riga intera, cambia un ruolo o uno strumento, aggiungi un credito mancante, oppure scegli l'edizione giusta dell'album. Queste correzioni restano sull'apparecchio, non toccano i file musicali ed entrano nei backup; Torna a MusicBrainz le annulla. La pagina dell'album indica poi che i crediti sono stati corretti a mano.
  • Artisti — scegli quale artista di MusicBrainz corrisponde davvero a un nome, mostra un nome diverso o nascondi la biografia.
E hifiplayer.local?

Il dispositivo risponde anche su http://hifiplayer.local per impostazione predefinita — è una scorciatoia, non un indirizzo fisso. È in realtà <nome-dispositivo>.local, quindi smette di funzionare (o punta a un altro dispositivo) nel momento in cui lo rinomini, ed è ambiguo appena hai più di un Osmium Sound con lo stesso nome in rete. L'indirizzo sempre corretto è l'indirizzo IP.

App companion Android

Controlla Osmium Sound dal telefono: sfoglia la libreria, gestisci riproduzione e coda, regola il volume. Non è disponibile su Google Play — è distribuita come APK firmato oppure tramite il repository F-Droid self-hosted del progetto.

  1. Installa l'app Scarica l'APK dalle Releases del progetto, oppure aggiungi il repository F-Droid — dettagli sul sito ufficiale.
  2. Abbina il dispositivo Dallo schermo del dispositivo (se in modalità "con schermo") vai su Impostazioni e mostra il QR code di abbinamento; oppure, per un dispositivo headless/solo server, genera il QR dall'amministrazione web. Scansionalo dall'app.
  3. Usa l'app Una volta abbinata, l'app parla direttamente con Lyrion e con l'API del dispositivo sulla rete locale.

Le impostazioni del dispositivo sono raccolte in Impostazioni → Osmium Sound, con le stesse sezioni dell'amministrazione web: uscita audio, sorgenti musicali, servizi, Lyrion Music Server, riproduzione e VU meter (compresi gli aspetti da scaricare), schermo, fuso orario, aggiornamenti, iPhone/iPad, backup e ripristino, sistema. Alcune cose restano di proposito solo nell'amministrazione web: rete, accesso SSH, account web, reset di fabbrica e strumenti di debug. Le animazioni di Now Playing si scelgono sullo schermo dell'apparecchio o nell'amministrazione web, non nell'app. Con un apparecchio più vecchio, le sezioni che non supporta ancora semplicemente non compaiono.

Una volta abbinata, l'icona di spegnimento nella barra in alto dell'app spegne l'apparecchio Osmium Sound, dopo averti chiesto conferma.

La prima volta che apri l'app ti chiede la lingua, poi a che cosa ti stai collegando. Scegli Osmium Sound per inquadrare il codice di abbinamento e avere le impostazioni del dispositivo elencate qui sopra, oppure un altro server Lyrion per scrivere a mano indirizzo e porta: in quel caso le impostazioni del dispositivo non compaiono, perché dietro non c'è un apparecchio Osmium. Se il collegamento non riesce, la guida "Problemi con il collegamento?" in quella schermata ti accompagna tra le cause più comuni.

Ascoltare sul telefono

Il telefono può anche essere uno dei lettori di casa. Compare nell'elenco dei lettori con un nome suo, accanto all'apparecchio Osmium e a tutti gli altri, e lo scegli allo stesso modo. La musica esce allora dall'altoparlante o dalle cuffie del telefono, mentre tutto il resto — libreria, coda, volume — continua a funzionare come sempre.

Nelle impostazioni, sotto "Questo telefono come lettore", puoi disattivarlo, cambiargli nome e scegliere quanto deve essere buono il suono, separatamente per Wi-Fi e rete mobile. La qualità migliore suona meglio e passa da un brano al successivo senza stacchi; quelle più leggere consumano molti meno dati.

  • Preferiti e playlist — il cuore in Now Playing aggiunge o toglie dai preferiti quello che sta suonando; tieni premuta una riga qualsiasi (un brano, un album, una stazione radio, una playlist) per fare di più: aggiungi alla coda, riproduci dopo, aggiungi ai preferiti. Nei Preferiti puoi rinominare, riordinare e togliere; le playlist si possono rinominare, eliminare e alleggerire di un brano.
  • Aggiornare la libreria — Impostazioni → Lyrion Music Server mostra quanti album, artisti e brani conosce il server, quando ha fatto l'ultima scansione, e un pulsante Aggiorna la libreria con l'avanzamento (c'è anche nella Dashboard dell'amministrazione web). Le sorgenti che aggiungi o cambi vengono scansionate da sole; usalo dopo aver spostato musica a mano. Nella stessa sezione, Informazioni su album e artisti accende o spegne le ricerche online per le pagine di album e artisti, può preparare con calma tutta la libreria in sottofondo così le pagine si aprono già complete, e cancella quello che è stato salvato. Per trovare le informazioni, l'apparecchio invia a MusicBrainz e Wikipedia i nomi dei tuoi album e artisti.
  • CD — inserisci un disco per riprodurlo oppure rippare in FLAC con tag e copertina automatici (MusicBrainz), direttamente nella libreria, su un disco USB adottato o su una condivisione di rete scrivibile. Un album rippato viene riconosciuto subito nella sua pagina.
  • Discover — mix infiniti per brano, album o artista, con filtro per genere e preset salvabili, oltre a "continua ad ascoltare musica simile", artisti correlati e biografie direttamente a schermo.
  • Impostazioni → Riproduzione — transizione tra i brani, ReplayGain, timeout di espansione automatica del now playing, e un interruttore volume fisso al 100% (BitPerfect) che disattiva il controllo volume digitale di Lyrion e disabilita visivamente lo slider del volume.
  • Impostazioni — info di sistema e rete, uscita audio, sorgenti musicali, Lyrion Music Server, VU meter, animazioni, aggiornamenti, abbinamento app companion, backup, reset di fabbrica.
La riproduzione sopravvive a un riavvio

Osmium Sound ricorda cosa stava suonando — brano, posizione e se era in riproduzione o in pausa — attraverso un riavvio o uno spegnimento, e riprende da solo non appena il dispositivo torna online.

VU meter

Now Playing può mostrare una coppia di VU meter analogici con gli aghi che si muovono con la musica. Tutto quello che li riguarda è in Impostazioni → VU meter — sullo schermo, nell'amministrazione web o nell'app companion:

  • Accesi o spenti — spegnili se preferisci uno schermo più pulito.
  • Aspetto — scegli uno degli stili dalla sua anteprima: sei sono già nell'apparecchio (Classic, Modulometer, Amber, Ice Blue, Exposed, Panoramic).
  • Altri da scaricare — nella stessa sezione trovi altri aspetti da scaricare. Uno nuovo viene solo proposto, mai installato da solo; un pallino dorato ti avvisa che c'è una novità. Una volta scaricato, un aspetto si tiene aggiornato da solo, resta dopo gli aggiornamenti di sistema e si può rimuovere in qualsiasi momento (se era in uso, l'apparecchio torna a Classic).
Solo aspetti controllati da noi

Gli aspetti da scaricare arrivano dall'elenco ufficiale di Osmium Sound, e l'apparecchio rifiuta qualsiasi cosa non corrisponda esattamente. Un aspetto che richiede una versione più recente dell'apparecchio lo dice, invece di installarsi.

Animazioni

Con i VU meter spenti, Now Playing può mostrare al loro posto un'animazione. Si sceglie in Impostazioni → Animazioni — sullo schermo o nell'amministrazione web:

  • Nessuna — al posto dei VU meter non compare nulla.
  • CD — un disco entra in un lettore, poi gira.
  • Vinile — il braccio con la puntina scende sul disco, poi il disco gira.
  • Musicassetta — una cassetta entra in una piastra, poi scorre.

Si muove solo mentre la musica suona: metti in pausa e rallenta fino a fermarsi. Quando parte un altro album, il disco o la cassetta esce e rientra. Il pulsante di Now Playing che mostra il testo della canzone passa dall'animazione al testo e viceversa.

VU meter o animazione

Le animazioni si vedono solo sullo schermo dell'apparecchio, e solo quando i VU meter sono spenti. Per vederne una, spegni prima Impostazioni → VU meter.

Sorgenti musicali

Osmium Sound legge la libreria musicale da una o più sorgenti, configurabili dalle Impostazioni (o durante il setup iniziale):

  • Cartella di rete — un NAS o una cartella condivisa su un altro computer. Non serve conoscerne l'indirizzo: il dispositivo cerca i computer e i NAS della tua rete, ne elenca le cartelle condivise e chiede nome utente e password in una piccola finestra solo se la cartella li richiede. Se non riesce a collegarsi, ti spiega il motivo a parole semplici (i dettagli tecnici restano a un tocco di distanza). Puoi comunque scrivere tutto a mano. Ogni cartella può essere resa scrivibile o di sola lettura in qualsiasi momento — comodo se vuoi anche rippare CD al suo interno.
  • Disco USB — un disco USB collegato al dispositivo, "adottato" (condiviso in rete, leggibile/scrivibile). Un disco adottato si rimonta da solo se lo scolleghi e ricolleghi, o dopo un riavvio.
  • Disco interno — un secondo disco dentro il dispositivo, dedicato alla musica.
  • Una cartella sull'apparecchio stesso — musica copiata direttamente sul disco del dispositivo. Può essere condivisa in rete, così ci copi la musica da un computer.

Dopo aver aggiunto o modificato una sorgente, la libreria si aggiorna da sola. Nell'amministrazione web, Sorgenti musicali è un menu — sorgenti attive, aggiungi sorgente, cartella playlist, cartelle condivise, gestisci i file — dove ogni schermata ha il suo modo per tornare indietro.

In Cartella playlist scegli dove vengono salvate le playlist; condividila in rete per copiarci playlist dal computer. Le playlist create su Windows vengono sistemate da sole, così suonano anche qui.

Server Lyrion esterno

Se il dispositivo segue un Lyrion Music Server già presente altrove in rete (scelto durante il setup, o in Impostazioni → Lyrion Music Server), la sezione Sorgenti musicali non compare: le sorgenti si configurano su quell'altro dispositivo, non su questo.

Streaming e plugin Lyrion

I servizi di streaming (Deezer, Qobuz, TIDAL, Spotify e altri) e le funzioni aggiuntive (UPnP/DLNA, AirPlay, radio) sono plugin di Lyrion Music Server, non parte dell'app Osmium Sound stessa. I più comuni si possono già spuntare durante il setup (il passaggio "Servizi musicali"); per gli altri, o per aggiungerne uno in seguito:

  1. Apri la web UI di Lyrion http://<ip-dispositivo>:9000 — vedi Amministrazione web per come trovare l'indirizzo IP.
  2. Vai su Impostazioni → Plugin Cerca e attiva il plugin del servizio che vuoi usare.
  3. Accedi con le tue credenziali Segui le istruzioni del plugin per il login al servizio.
  4. Torna sull'interfaccia Osmium Sound Il nuovo servizio compare da solo nei tab Radio/App — non serve nessun aggiornamento dell'app.

Server Lyrion esterno

Ogni dispositivo Osmium Sound suona di default attraverso il proprio Lyrion Music Server. Da Impostazioni → Lyrion Music Server puoi scegliere tra Interno ed Esterno (sulla mia rete): il secondo usa un server Lyrion già in funzione su un altro dispositivo, trovato per te con una ricerca nella rete — puoi anche scriverne l'indirizzo IP o il nome, per esempio nas.local. Un nome che non si trova viene rifiutato prima di cambiare qualsiasi cosa. Il cambio riavvia il dispositivo. Nella stessa sezione ci sono il nome del player, la versione di Lyrion e l'aspetto del player web.

Far suonare più player in sincronia (multiroom) è una funzione nativa di Lyrion Music Server, gestita dalla sua stessa interfaccia — Osmium Sound non offre una funzione di multiroom propria. Assegna un nome a ogni dispositivo per distinguerli facilmente lì. Dallo schermo del dispositivo puoi anche comandare qualsiasi altro player dello stesso server — vedi Uso quotidiano.

Backup e ripristino

Dalle Impostazioni puoi creare un backup completo della configurazione del dispositivo: uscita audio, elenco delle sorgenti musicali, preferenze e playlist di Lyrion, profili di rete Wi-Fi, account e token di abbinamento. I dati sensibili (reti Wi-Fi, account) entrano nel backup solo se scegli di proteggerlo con una passphrase.

  • Backup manuale — Impostazioni → Backup → Crea backup adesso, con o senza passphrase.
  • Backup programmato — attivabile in Impostazioni; esegue automaticamente un backup settimanale (solo dati non sensibili, dato che non c'è nessuno a cui chiedere una passphrase).
  • Ripristino — dalle Impostazioni di un dispositivo già configurato, oppure direttamente durante il setup guidato del primo avvio (vedi Primo avvio e configurazione) per rimettere in piedi rapidamente un dispositivo sostituito o reimpostato.
Prima di un ripristino

Il dispositivo crea automaticamente un backup di sicurezza dello stato corrente subito prima di applicare un ripristino, così un ripristino sbagliato è comunque reversibile.

Aggiornamenti OTA

Osmium Sound e Lyrion Music Server si aggiornano via internet (OTA, over-the-air) da Impostazioni → Aggiornamenti — sullo schermo, nell'amministrazione web o nell'app companion — senza mai dover riflashare la chiavetta USB dopo l'installazione iniziale. Premi Controlla aggiornamenti: entro un minuto ti dice che c'è un aggiornamento, che sei già aggiornato, oppure che non è riuscito a controllare (di solito un problema di rete).

L'intero sistema arriva come un unico pacchetto firmato digitalmente: il dispositivo rifiuta qualsiasi cosa non sia firmata correttamente, anche se qualcuno riuscisse a manometterne il download. Il dispositivo tiene due copie del sistema una accanto all'altra. L'aggiornamento viene scritto nella copia che non è in uso, mentre il dispositivo continua a funzionare, con l'avanzamento mostrato in tempo reale; il riavvio finale passa alla copia nuova. Se la nuova versione non parte come dovrebbe, il dispositivo torna da solo a quella precedente, entro una decina di minuti. Impostazioni, musica e tutto ciò che hai scaricato sono tenuti separati dal sistema, quindi un aggiornamento non li tocca mai.

Apparecchi installati prima delle due copie

Un apparecchio più vecchio passa alla nuova sistemazione con un normale aggiornamento — senza reinstallare, e mantenendo impostazioni e musica. Quell'aggiornamento dura più del solito e riavvia il dispositivo alcune volte da solo; lascialo finire senza spegnerlo.

Ogni dispositivo può scegliere un canale di rilascio in Impostazioni → Aggiornamenti:

CanaleDescrizione
Prod (predefinito)Versioni stabili, consigliato per l'uso quotidiano
DevVersioni di sviluppo più frequenti, per chi vuole provare le novità in anteprima
Riavvio finale

Una volta applicati tutti i passaggi di un aggiornamento, il dispositivo si riavvia da solo per completarlo — è normale, e la riproduzione riprende automaticamente subito dopo (vedi Uso quotidiano).

SSH e accesso avanzato

L'accesso SSH è disattivato per impostazione predefinita. Può essere attivato dalle Impostazioni (a schermo o da amministrazione web → Servizi) per manutenzione avanzata o debug. Subito sotto l'interruttore scegli nome utente e password con cui entrare; il pannello mostra poi il comando ssh esatto da usare.

Sicurezza

Quando SSH viene attivato, l'accesso come utente root resta comunque sempre bloccato: non è possibile entrare direttamente come amministratore di sistema via SSH.

Installare programmi aggiuntivi

Il sistema in sé non si può modificare, ma via SSH il solito sudo apt install <pacchetto> funziona ancora: il programma aggiuntivo viene tenuto separato dal sistema, e sudo apt remove lo toglie di nuovo. Dopo un aggiornamento di sistema il dispositivo, all'avvio, ricostruisce da solo i programmi aggiuntivi per la nuova versione (per farlo gli serve internet). Un pacchetto che sostituirebbe una parte del sistema, o che richiede componenti di sistema più recenti di quelli presenti, viene rifiutato con una spiegazione. Il sistema invece non si aggiorna con apt upgrade ma da Impostazioni → Aggiornamenti.

Accesso remoto (Tailscale)

L'amministrazione web offre anche un accesso remoto opzionale via Tailscale, per raggiungere il dispositivo da fuori casa — sul tuo account Tailscale, non su un servizio gestito da terzi.

  1. Installa Tailscale Da amministrazione web → Impostazioni → Tailscale, installalo sul dispositivo se non è già presente.
  2. Attivalo L'attivazione apre un link di login monouso — aprilo nel browser e accedi al tuo account Tailscale (o creane uno) per autorizzare il dispositivo sulla tua tailnet.
  3. Connettiti da qualsiasi luogo Una volta connesso, l'indirizzo IP Tailscale del dispositivo e i dettagli della connessione (inclusa regione/latenza del relay DERP) compaiono nella stessa sezione delle Impostazioni. Raggiungi l'amministrazione web da quell'indirizzo, da qualunque altro dispositivo sulla tua tailnet.
Solo da amministrazione web

Al momento Tailscale è disponibile solo dall'amministrazione web — non compare nelle Impostazioni a schermo né nell'app companion Android.

Reset di fabbrica

Il reset di fabbrica cancella tutte le impostazioni, l'account di amministrazione web, le sorgenti configurate, i backup conservati sull'apparecchio e gli aspetti dei VU meter scaricati, poi riavvia il dispositivo direttamente nella configurazione descritta in Primo avvio e configurazione — come se fosse appena stato installato. La musica copiata sull'apparecchio stesso resta.

È disponibile:

  • A schermo, in Impostazioni → Controlli Sistema → Reset di fabbrica (se il dispositivo è in modalità "con schermo").
  • Dall'amministrazione web, inserendo la password dell'account amministratore.
Password dimenticata?

Se dimentichi la password dell'amministrazione web, puoi reimpostarla dalle Impostazioni a schermo (se disponibile) oppure procedere con un reset di fabbrica.
