    Hardware requirements

    What you need

    No high-end hardware needed: Osmium Sound runs well on inexpensive or recycled mini PCs. Details in the manual.

    New: UEFI is no longer a requirement. From version 2.5.25 Osmium Sound installs and starts on PCs with UEFI and also on older PCs with a traditional BIOS, so even a PC from before 2015 can become your music player.

    Components

    Computerx86-64 (64-bit) mini PC, with UEFI or with a traditional BIOS: both work from version 2.5.25.
    StorageInternal disk/SSD to install onto (16 GB recommended, 8 GB minimum)
    USB stick8 GB or larger, needed only for the initial install
    Screen (optional)Touchscreen recommended for “with screen” mode. Supported resolutions are the ones in Settings: Automatic, 1280×720, 1920×1080 or the screen’s native resolution. Not needed in headless or server-only mode.
    Audio outputUSB DAC or HDMI output
    NetworkEthernet or Wi-Fi
    Setup deviceAny device with a browser — phone, tablet or PC — for installation and first setup

    Processors found in most mini PCs

    Intel Corei3/i5/i7/i9 from the 6th generation “Skylake” (2015) onwards, Core Ultra too
    Intel Celeron / Pentium / Atom / N-series“Braswell” (2015), “Apollo Lake” (2016), “Gemini Lake” (2017–2019), “Jasper Lake” (2021), “Alder Lake-N” (N95/N100/N200/i3-N305, 2023), “Twin Lake” (N150, 2025) — the chips found in most mini PCs
    AMDAny Ryzen (2017 onwards, every generation) or Athlon on the AM4 socket; A-series APUs “Carrizo” (2015) and “Bristol Ridge” (2016)
    Older PCsFrom version 2.5.25 they work too, even without UEFI: the installer also starts in BIOS mode
    AvoidAtom “Bay Trail”/“Cherry Trail” tablets and HDMI sticks (2013–2015): many have a 32-bit UEFI that cannot boot the 64-bit image
    Get started

    Download & install

    Flash one ISO image to a USB stick for the first install. From then on, every new version arrives over the air: it is installed next to the current one while the device keeps playing, and if it does not start properly the device goes back to the previous one by itself.

    Runs on standard x86 PCs, with UEFI or with a traditional BIOS: from version 2.5.25 older PCs without UEFI work too. Chromebooks are not supported. See the requirements.

    The simplest way

    Osmium Flasher does it all for you: it downloads Osmium Sound, checks that the file is intact, copies it to the USB stick, then shows you step by step how to start the mini PC and finish the installation. No other program needed, and no way to wipe the computer you are using by mistake.

    Download Osmium Flasher for Windows
    Download Osmium Flasher for Linux

    Make it executable with chmod +x Osmium-Flasher-*.run and run it.

    On macOS there is no Osmium Flasher. Download the ISO and write it to a USB stick (8 GB or more) with balenaEtcher. Everything after that — booting the mini PC and running the installer — is exactly the same.

    Common installation issues

    Secure Boot — you can leave it on: the installer and the installed system are signed. If a machine still refuses to start from the stick, turn it off in the firmware setup.

    Windows — “unknown publisher”. Osmium Flasher is not code-signed, so SmartScreen stops it the first time. Click More info, then Run anyway. Windows will also ask for administrator rights: they are needed to write to the USB stick.

    Linux — password prompt. You will get a polkit password prompt when the write starts. It is a self-extracting executable rather than an AppImage on purpose — an AppImage is mounted so that root cannot read it, which is exactly what the elevated write needs to do.

    Chromebooks — their firmware is locked down by the manufacturer and refuses to boot anything else, unless you flash third-party modified firmware (not provided or endorsed by the manufacturer) and/or use drivers dedicated to that specific platform — neither of which this project provides or supports.

    Note: the installer asks which disk to install on before formatting it — nothing is wiped without confirmation (the ISO is only needed for the first install, every later version arrives automatically over the air).

    Try it live: pick Try Osmium Sound (no install) at the boot menu to run the interface straight from the USB stick, nothing written to disk.

    Verified on the platforms we tested: there, every feature has been checked and validated. The x86 hardware landscape is vast, though: we can't rule out issues on other hardware combinations. If you run into one, please report it through the official channels below — it really helps.

    Coming back from the private beta?

    Were you in the private beta on a Debian 12 build? You need to reinstall from the latest ISO above: starting with the next release, Debian 12 is no longer supported and will not receive over-the-air updates any more — so you will not be able to update from it.

    On iPhone and iPad

    There is no Osmium companion app for Apple devices. We suggest LyrPlay, a third-party app by Eric Miller: it connects to the Lyrion Music Server running on your Osmium device, gives you the Material interface to drive playback, and can also turn the iPhone or iPad itself into another player on the network. It is free, with an optional paid icon pack. It is not our app, we have no connection with its author and we cannot support it — we are simply recommending something that works well with Osmium Sound.

    LyrPlay on the App Store

    Scan it to open LyrPlay in the App Store on your phone.

    Note: the APK and our own F-Droid repository give you the very same app as Google Play, for phones without Google services or if you simply prefer it that way. For automatic updates outside Google Play use F-Droid: tap Add F-Droid repo above (F-Droid app required), or add https://osmiumsound.it/fdroid/repo manually under Settings → Repositories. Whichever way you install it, your phone and the device must be on the same local network.
